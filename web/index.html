Under the hood

Evidence, not guesses.

WeightWise does not trust filenames, sizes alone, or modification dates. It proves content equality before it calls anything a duplicate.

01

Inventory, then narrow.

A full directory pass builds an inventory. Only files with an identical byte size are worth fingerprinting.

02

Full-file fingerprints.

Each candidate is streamed through SHA-256. Identical fingerprints are treated as identical bytes, regardless of filename.

03

Keep one, review the rest.

Smart keep recommends the cleanest path. Deletion is locked to one surviving copy and every file is re-verified first.
